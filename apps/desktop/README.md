# DeepSeek Harness — Desktop shell

`@deepseek-ai/dsh-desktop` is an [Electron](https://www.electronjs.org/) shell
that runs the DeepSeek Harness web UI as a native desktop application. Instead
of starting `dsh web` in a terminal and keeping a browser tab open, the desktop
app launches the local server itself, waits for it to become healthy, and hosts
the UI in its own embedded Chromium window. It belongs in the repo's `apps/`
app tier alongside `apps/cli` and `apps/web`.

## How it works

The Electron main process (`src/main.mjs`):

1. Locates the repository root by walking up to the `@deepseek-ai/dsh-root`
   package.
2. Spawns `dsh web` as a child process from that root.
3. Polls the default URL `http://127.0.0.1:3080` (override with the
   `DSH_DESKTOP_PORT` environment variable) until it responds with HTTP 2xx.
4. Creates a hidden-then-shown `BrowserWindow` loading that URL.
5. Tears the server down when the app quits.

External links are delegated to the system browser; `nodeIntegration` is off
and `contextIsolation` is on, so the hosted UI has no access to Node.

## Run from source

```sh
pnpm install
pnpm --filter @deepseek-ai/dsh-desktop start
```

`pnpm --filter @deepseek-ai/dsh-desktop dev` opens the DevTools along with the
window.

## Smoke test

`pnpm --filter @deepseek-ai/dsh-desktop smoke` launches the server, loads the
UI once without surfacing a window, captures `smoke/smoke.png`, prints the page
title, and exits. It is the deterministic check that the server and renderer
both come up.

## Port

The port defaults to `3080` (the same default as `dsh web`). If that port is
already taken by a running `dsh web` instance, start the desktop app with a
different port:

```sh
DSH_DESKTOP_PORT=3101 pnpm --filter @deepseek-ai/dsh-desktop start
```

## Icon

`resources/icon.png` is generated by `apps/desktop/scripts/generate-icon.mjs`
(plain Node, no dependencies):

```sh
node apps/desktop/scripts/generate-icon.mjs
```

## Packaged distributables

A packaged installer that bundles the full harness server and a runtime is not
included yet; the current scope is the source-run desktop shell. The
`electron-builder` packaging step is a natural follow-up.
